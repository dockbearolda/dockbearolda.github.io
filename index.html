Publier sur tous les appareils

Tes modifications sont déjà enregistrées sur cet appareil. Pour les envoyer sur le portail (téléphone, PC, collègues), il faut une seule fois un jeton GitHub. Il reste sur cet appareil.

  1. Créer un jeton GitHub
  2. Repository access → Only select repositories → dockbearolda.github.io
  3. Permissions → Contents → Read and write, puis « Generate token »
  4. Colle-le ci-dessous
